## Reporting a Vulnerability

ZenithIstanbul audits codebases for security boundary breaches (CWE-668, CWE-200, CWE-798). We take the security of this platform and its users seriously.

If you discover a security vulnerability within ZenithIstanbul itself (e.g. CSRF firewall bypass, path traversal vulnerability, ReDoS in regex parsers):

1. **Do not disclose the issue publicly** on GitHub issues or social media.
2. Email details and reproduction steps to: **cagrigiraykesan@gmail.com**
3. Please include:
   - Nature of the vulnerability
   - Step-by-step reproduction instructions or proof-of-concept
   - Potential impact on client or server environments

You will receive an acknowledgment within 48 hours, followed by a timeline for resolution.
